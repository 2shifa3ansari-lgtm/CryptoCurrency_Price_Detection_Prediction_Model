# CryptoCurrency_Price_Detection_Prediction_Model
A machine learning project that forecasts cryptocurrency prices using historical market data.

# 📊 Time Series Analysis with Cryptocurrency

## 🚀 Project Overview
This project focuses on analyzing and forecasting cryptocurrency prices using data analytics and machine learning techniques. It uses historical Bitcoin data to identify trends and predict future price movements.

---

## 🎯 Objectives
- Collect cryptocurrency data  
- Perform data preprocessing  
- Analyze trends using visualization  
- Apply forecasting models (ARIMA, LSTM, Prophet)  
- Build an interactive dashboard  

---

## 📂 Project Structure

---

## 📊 Data Collection
Data is collected using the **yfinance** library.

- Cryptocurrency: Bitcoin (BTC-USD)  
- Historical data used in notebook  
- Real-time data used in dashboard  

---

## 🧹 Data Preprocessing
- Handling missing values  
- Converting Date to datetime  
- Converting numeric columns  
- Sorting data  
- Removing invalid and duplicate records  

---

## 📈 Models Used
- **ARIMA** – Statistical time series model  
- **LSTM** – Deep learning model  
- **Prophet** – Forecasting model developed by Facebook  

---

## 📉 Features
- Price trend visualization  
- Volatility analysis  
- Forecasting models  
- Interactive dashboard  
- Simulated sentiment analysis
